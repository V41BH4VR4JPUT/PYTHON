# File and Directory Management System

This repository contains a **File and Directory Management System** implemented in Python. The project leverages the `os` module to perform various file and directory operations, making it a practical tool for system administrators and Python enthusiasts.
---

## Key Features

1. **List Files and Directories**
   - Display all files and directories in the current working directory.

2. **Create a Directory**
   - Create a new directory with a user-specified name.

3. **Rename a File or Directory**
   - Rename an existing file or directory.

4. **Delete a File or Directory**
   - Delete a file or an empty directory.

5. **Change Current Working Directory**
   - Navigate to a different directory.

6. **Check File/Directory Properties**
   - Display properties such as size, creation time, and last modified time.

7. **Search for a File or Directory**
   - Search for a file or directory by name in the current directory.

---

## Technologies Used

- **Programming Language:** Python
- **Modules:** `os`, `time`

---

## Code Highlights

### **Key Functions**
1. **`list_files_and_directories()`**
   - Lists all files and directories in the current working directory.

2. **`create_directory()`**
   - Creates a new directory with a name provided by the user.

3. **`rename_file_or_directory()`**
   - Renames an existing file or directory.

4. **`delete_file_or_directory()`**
   - Deletes a specified file or directory.

5. **`change_directory()`**
   - Changes the current working directory to a specified path.

6. **`check_properties()`**
   - Displays properties like file size, creation time, and last modification time.

7. **`search_file_or_directory()`**
   - Searches for a file or directory by name.

8. **`main_menu()`**
   - Provides an interactive menu-driven interface for performing all operations.
