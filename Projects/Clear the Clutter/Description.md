# 🗂 Clear the Clutter  

## 📌 Overview  
Clear the Clutter is a Python script that organizes files in a folder by renaming them sequentially based on their extensions. It also allows you to remove unwanted files of specific types.  

## 🚀 Features  
- **Automatic Renaming**: Renames all `.png` files in order (e.g., `1.png`, `2.png`, ...).  
- **File Deletion**: Removes unwanted `.pdf` files.  
- **Folder Optimization**: Scans and processes files dynamically.  

## 🛠 Technologies Used  
- Python  
- `os` module
